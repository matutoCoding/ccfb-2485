# 探鱼器回波仿真系统

浏览器内运行的渔船探鱼器(fishfinder)回波仿真,用于渔港门店选型讲解和渔民上船前识图培训。
纯 **TypeScript + 手写 WebGL2 着色器**,零运行时第三方依赖;海区/鱼群/换能器/航次/设置全部存 **IndexedDB**。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run selftest   # 物理精度自检(Node 直接运行,21 项)
```

## 六个页面

| 页面 | 功能 |

| 海区场景 | 水深网格(双线性插值)、泥/沙/礁底质涂刷、斜坡抬升/降低、温跃层、波束盲区估算表 |

| 回波显示 | 双频瀑布图 + A 显示、增益/TVG/杂波/色标、四类噪声叠加、底锁/缩放、点击反查三维 |
| 航次回放 | 地图点选编辑航线、船速曲线、抛锚停留、回放预览(鱼弧随船速变化) |
| 设置 | 全局参数、精度自检面板、数据导入导出、恢复出厂 |

## 物理模型(纯 TS,可在 Node 独立验证)

- **声速**:Mackenzie (1981) 九项式,随温盐深变化
- **吸收**:频率相关经验表(Francois-Garrison 同量级),50k≈12 dB/km、200k≈70 dB/km
- **声源级**:`SL = 170.8 + 10log₁₀(P) + 个体修正`
- **波束指向性**:圆活塞 `2J₁(x)/x`,双程损失,旁瓣地板 -40 dB
- **鱼回波(点目标)**:`EL = SL - 2TL + TS - 波束损失`,`TL=20logR+αR`
- **海底回波(面目标)**:等效束宽法 `EL=SL-2TL+Sb+10log(r·Φ·Δr)`,泥/沙/礁各有反向散射强度、粗糙度展宽、二次回波衰减
- **TVG**:`40logR+2αR`(鱼群)/ `20logR+αR`(底质),近场钳制
- **月牙弧**:逐 ping 按鱼-船实时三维几何算斜距与偏轴角,斜距变化自然成弧,非贴图
- **盲区**:斜坡几何盲区 `r·tan(β/2)·tan(α)` + 脉宽分辨单元;贴底鱼进入盲区标记为被海底吞噬
- **昼夜迁移**:晨昏平滑过渡,白天沉底、夜间上浮

## 精度验收(`npm run selftest`,21 项)

两条硬指标:

1. **月牙弧几何**:弧顶深度误差 ≤ 1 个距离门行(实测 50k 0.24 行 / 200k 0.29 行);弧宽与圆活塞波束角理论值误差 ≤ 1 m
2. **TVG 距离一致性**:同一条鱼 10m 与 80m 输出色阶差 ≤ 1 dB(实测 0.052 / 0.038 dB;声纳方程手算差 0.000 dB)

另含:高速鱼弧压扁(时间轴弧宽收窄)、抛锚鱼弧拉横线(峰值 bin 恒定)、盲区吞噬/对照可见、底质与二次回波强度序、双频可区分。

## 目录结构

```
src/
  core/         声学物理与仿真引擎(无 DOM 依赖,可 Node 运行)
    acoustics.ts  声速/吸收/声纳方程/波束/TVG
    seabed.ts     地形插值/脚印/盲区/底质
    fish.ts       鱼群布放/昼夜迁移
    echo-engine.ts 逐 ping 回波引擎
    voyage.ts     航线时间线
    simulation.ts 编排(多换能器 + 时钟)
  render/       WebGL2/Canvas2D 渲染器(手写 shader)
    waterfall.ts  环形纹理瀑布图
    view3d.ts     海底网格/声束锥/鱼群三维
    ascope.ts     A 显示曲线
    area-map.ts   海区 2D 编辑图
  data/         IndexedDB 封装 + 内置测试数据 + 全局 store
  ui/           六个页面与路由
test/selftest.ts  物理精度自检
```

## 内置测试数据(无需自备)

- 舟山近海试验海区:40×30 网格(800×600m),含浅-深斜坡、礁石垄、泥质洼地、温跃层
- 5 个鱼种(鳀鱼/蓝圆鲹/带鱼/真鲷/大黄鱼),4 个鱼群
- 4 个换能器:50k/40° 宽束、200k/11° 窄束、88k/24° 中束、200k/25° 低成本
- 含高速段与抛锚段的示例航线
