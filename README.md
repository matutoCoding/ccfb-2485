# 渔船探鱼器回波仿真系统

纯浏览器端的探鱼器声呐仿真：TypeScript + WebGL2 自写着色器，零前端框架、零图形库，数据存 IndexedDB。
面向渔港门店的选型讲解和渔民上船前的看图训练。

## 运行

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建到 dist/
npm run selftest   # Node 无头物理几何自检（13 项）
npm run e2e        # Puppeteer 端到端冒烟测试（需先起 dev，SIM_URL 指定地址）
```

## 物理模型要点

- **声呐方程**：`EL = SL + TS − 2·TL + 双程波束指向性`，`TL = 20logR + αR`
- **月牙弧几何**：鱼静止、船匀速穿过，斜距 `R=√(d²+x²)`；弧宽 `W=2d·tanβ`，弧缘下垂 `sag=d(1/cosβ−1)`
- **TVG**：单目标 `40logR+2αR`、鱼群 `30logR+2αR`，82dB 硬件封顶；CPU 与 GLSL 同一份公式
- **距离门**：0.1m/像素行（BIN_M），脉宽升余弦包络展宽
- **底质**：泥/沙/礁各有反向散射强度、粗糙度（展宽）、二次回波衰减；底回波对贴底鱼取强者覆盖（吞没）
- **波束盲区**：声线沿海床步进采样，陡坡/礁石遮挡的目标不产生回波
- **噪声**：环境底噪、尾流气泡（近场随航速）、发动机水平条纹、别船串频突发脉冲、温跃层、DSL 散射层
- **显示链**：R32F 浮点纹理存原始电平，GLSL 内做 TVG/增益/杂波抑制/噪声基底追踪门限（NBT）/LUT 色标

## 验收自检（npm run selftest）

最关键的两条几何/显示指标：

1. **月牙弧**：弧顶深度、逐点弧迹 `R=√(d²+x²)`、弧宽 `2d·tanβ`、弧缘 sag，仿真与理论公式误差均 **≤ 1 个像素行（0.1m）**，实测弧迹最大偏差 0.00 行
2. **TVG 等色阶**：同一条鱼在 10m 与 80m，TVG 补偿后显示电平差 0.000dB，量化色阶 128 vs 128（差 0 级）

另有底质回波排序、二次回波、抛锚横线、频率相关吸收、陡坎盲区、贴底鱼吞没等共 13 项。
设置页内提供同样算法的 12 项可视化自检（一键运行）。

## 目录结构

```
src/core/      物理与数据：physics 声呐方程、engine 逐 ping 引擎、world 海区/鱼群、
               colormaps 色标与显示映射、db IndexedDB、seed 内置种子数据、store 状态
src/render/    waterfall WebGL2 瀑布图、gl3d 极简三维引擎、adisplay A 显示曲线
src/pages/     六个页面
scripts/       selftest 无头自检、e2e-smoke 冒烟、screenshot 截图
```

## 内置种子数据

- 1 个演示海区（600×500m，水深 6–95m，含海槽、礁石隆起、西泥/中沙/东礁分区）
- 4 鱼种（鳀鱼、竹荚鱼、带鱼、真鲷）、4 换能器（50k/200k × 宽/窄波束）、3 鱼群、2 航次
- IndexedDB schema 版本升级时自动重建种子，设置页可手动恢复
